## 🚀 Product Overview
FinDash is a **production-grade personal finance SaaS** designed to help users track expenses, predict recurring bills, and achieve savings goals using privacy-first AI. Unlike standard CRUD trackers, FinDash leverages a **heuristic-based AI engine** to provide actionable financial coaching without exposing raw sensitive data to external LLMs.

**Key Problem Solved:** Most finance apps are either too complex (Excel) or too automated (lack of control). FinDash bridges this gap with **Intelligent Assistance**—automating the tedious parts (categorization, bill prediction) while keeping the user in the driver's seat.

## ✨ Key Features
- **🤖 Privacy-First AI Coach**: Local-heuristic engine analyzes spending patterns to offer safe, personalized saving tips.
- **🔮 Smart Bill Prediction**: Uses fuzzy matching logic to forecast upcoming recurring bills (e.g., Netflix, Rent) with confidence scoring.
- **📊 Real-Time Analytics**: Interactive charts for category breakdowns, monthly trends, and savings rates using optimized Firestore listeners.
- **🎮 Demo Mode**: A fully interactive, read-only "Sandbox" environment allowing instant product exploration without user friction.
- **🔒 Enterprise-Grade Security**: Row Level Security (RLS) via Firestore Rules, protected routes, and rigorous input validation.
- **💎 Freemium Architecture**: Scalable data model supporting Free vs. Premium tiers with feature-gated UI components.

## 🏗 Architecture & Design
The application follows a **Service-Oriented Architecture (SOA)** on the frontend to decouple UI from data providers:

```mermaid
graph TD
    UI[React Components] --> Hooks[Custom Hooks]
    Hooks --> Services[Service Layer (Singleton)]
    Services --> Firebase[Firebase SDK]
    Firebase --> Firestore[Firestore NoSQL DB]
    
    subgraph "AI Layer"
    Services --> AIEngine[Heuristic AI Engine]
    AIEngine --> LocalData[Local Analysis]
    end
```

### Security & Privacy Approach
*   **Zero-Trust Data Access**: All database requests are validated via **Firestore Security Rules**. Users can strictly read/write only their own `uid` scoped documents.
*   **Privacy-by-Design**: The AI Coach runs analysis logic client-side on fetched data or via sanitized cloud functions, ensuring raw financial transaction lists are never blindly sent to third-party AI APIs.

## 💼 Monetization Strategy
Simulates a real-world SaaS business model:
*   **Free Tier**: Basic tracking, manual entry, "Teaser" AI insights.
*   **Premium Tier**: Unlimited AI coaching, automated bill prediction, custom goal tracking.
*   **Implementation**: Feature flagging via user role (`isPremium` boolean) stored in immutable user profiles.

## 🏁 Getting Started

### Prerequisites
*   Node.js 18+
*   npm or yarn

### Installation
1.  **Clone the repo**
    ```bash
    git clone https://github.com/adarsh438/Finance_manager.git
    cd Finance_manager
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Environment Setup**
    Create a `.env` file with your Firebase credentials:
    ```env
    VITE_FIREBASE_API_KEY=your_key
    VITE_FIREBASE_AUTH_DOMAIN=your_domain
    VITE_FIREBASE_PROJECT_ID=your_project_id
    # ... other firebase config
    ```

4.  **Run Locally**
    ```bash
    npm run dev
    ```
